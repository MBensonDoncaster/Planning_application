# Council logo

`doncaster-council.png` is the original white City of Doncaster Council logo, downloaded from the council website for the requested header branding:

https://www.doncaster.gov.uk/Themes/DMBC.Theme2/Content/images/template/logo.png

The image is bundled and served locally. Replace it when rebranding a copied template, and update the logo's alt text and home-link label in `src/components/AppHeader.tsx`.
